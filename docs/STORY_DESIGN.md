## 1. ที่มาของเนื้อหา

- สถานการณ์ ตัวเลือก A/B เฉลย และคำอธิบาย มาจากเอกสารต้นฉบับ (เปลี่ยน "น้องมดแดง" เป็น "มะลิ")
- ข้อความตามต้นฉบับเก็บไว้ครบในช่อง `sourceText` (ตัวเลือก) และ `explanationSource` (คำอธิบาย) เพื่อใช้ตรวจทางคลินิก
- ข้อความที่แสดงในเกม (`text`, `explanation`) ปรับเป็นภาษาเด็ก ประโยคสั้น โดยไม่เปลี่ยนความหมาย
- ส่วนที่เขียนเพิ่ม (ไม่มีในเอกสาร): บทสนทนาเชื่อมเรื่อง, feedback, คำใบ้ — **ไม่มีข้อมูลทางการแพทย์ใหม่**

## 3. ขั้นตอนในแต่ละภารกิจ

1. บทนำ — ผู้บรรยาย/มะลิเล่าสถานการณ์
2. ปุยถามคำถาม (มี `questionSimple` สำหรับ Guided Mode)
3. การ์ด 2 ใบ: **A ซ้าย · B ขวา** แต่ละใบมีรูป 1 รูป + ข้อความใต้รูป
4. เลือก → feedback ของตัวเลือกนั้น — ถ้าไม่ใช่ข้อที่เหมาะสม ใช้ "ไม่เป็นไรนะ… ลองเลือกอีกครั้งนะ" และเลือกใหม่ได้
5. ปุ่ม 💡 คำใบ้ 2 ระดับ · ไม่มีจับเวลา · กด ⏸ พักได้ตลอด
6. เลือกข้อที่เหมาะสมแล้ว → "ต่อไป" → ปุยอธิบายความรู้ (`explanation`)
7. บทปิด (outro) → ภารกิจถัดไป (`nextMission`)

## 4. NEED CLINICAL REVIEW (ทุกภารกิจ)

| ภารกิจ | ประเด็นที่ต้องยืนยัน |
|---|---|
| M01 | คำอธิบายเรื่องระดับยา · เวลา 20.00 น. เป็นตัวอย่าง เด็กแต่ละคนมีเวลาตามแผนของตน |
| M02 | การหยุดยากะทันหันทำให้ชักซ้ำ |
| M03 | แสงกะพริบจากจอ (มีผลเฉพาะบางคน) และการอดนอนเป็นสิ่งกระตุ้น |
| M04 | ความร้อนและไข้เป็นสิ่งกระตุ้น |
| M05 | ตัวอย่างอาการ Aura (แสงวูบวาบ หวิวในท้อง) ต่างกันในแต่ละคน · การให้เด็กนั่ง/นอนลงเอง |
| M06 | ใช้กับช่วง "อาการเตือน" เท่านั้น — ระหว่างชักจริง ผู้ใหญ่ดูแลตามแผนเฉพาะบุคคล เด็กไม่เคลื่อนย้ายตัวเอง |
| M07 | การจัดท่านอนตะแคงเป็นหน้าที่ของผู้ใหญ่ |

**ข้อสังเกตความขัดแย้งกับข้อกำหนดเดิม:** M05–M06 สอนให้เด็กดูแลตัวเองเบื้องต้นเมื่อมีอาการเตือน (นั่ง/นอนลง เลือกที่ปลอดภัย) ซึ่งเป็นไปตามเอกสาร แต่ข้อกำหนดเดิมห้ามให้เด็กจัดการอาการชักเอง — ในเกมจึงให้คุณครูเข้ามาดูแลต่อทุกครั้งใน outro และควรให้แพทย์ยืนยันขอบเขตนี้

- **รูปตัวเลือก 16 รูป** — ต้องทำ: `/assets/choices/m01_a.png` … `m08_b.png` (ดูคำบรรยายจาก `sourceText`)
  - ⚠️ M03, M05: ห้ามวาดแสงกะพริบหรือแสงวาบจริง ใช้สัญลักษณ์นิ่งแทน

- **การ์ดความทรงจำ** — `/assets/memories/area1–4.png`
- **โลโก้เกม**, หนังสือนิทาน (ฉากเปิด)
- **เสียงพากย์** ทุกบรรทัด (ช่อง `voice` รองรับไว้แล้ว)

## 6. ข้อเสนอ (รออนุมัติ)

1. **สลับตำแหน่ง A/B** — ไม่ทำ เพราะเอกสารกำหนดให้ A ซ้าย B ขวา และเฉลยกระจายแล้ว (A 5 ข้อ, B 3 ข้อ)
2. **Supported Mode** — เพิ่มปุ่ม "ผู้ดูแลช่วยเลือก" เพื่อบันทึกการช่วยเหลือแยกจากคำตอบ
3. **ฉากสวน s04/s05** — ถ้าต้องการใช้ อาจย้าย M04 ไปฉากสนามโรงเรียน (ยังไม่มีภาพ) หรือใช้ s05 เป็นที่ร่มให้มะลิพัก
